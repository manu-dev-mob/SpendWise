# SpendWise
Full-stack personal finance application using Flutter for the frontend and Firebase for authentication and data storage.
## Features
- 🔐 Firebase Authentication
- 📊 Interactive dashboard with charts
- 🧾 Expense management (add, edit, delete)
- 📅 Monthly analytics & category breakdown
- 🌐 Responsive web UI

## Tech Stack
- Flutter (Web)
- Firebase Authentication
- Cloud Firestore
- Provider (State Management)
- fl_chart
